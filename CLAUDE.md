# Primer pipeline

This repo builds Prerak's industry primer series (278 TradingView watchlist sections, Indian listed universe).

- For any primer work, use the `industry-primer` skill in `.claude/skills/industry-primer/SKILL.md`.
- Start every session with `git pull` and `python b1/prices_io.py unpack`.
- `CHECKLIST.md` says what is done and what is next; `FAMILY_NOTES.md` holds the running theses and known data traps.
- Data correctness is a hard requirement, and depth is never traded for speed.
- Commit and push after every finished primer.
